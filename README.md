# Manual de análisis de datos con R y Python

## Descripción del proyecto

Este repositorio contiene material educativo para aprender análisis de datos mediante los lenguajes de programación R y Python.

Los manuales están diseñados para desarrollar ejercicios paso a paso, desde la creación y exploración de conjuntos de datos hasta su transformación, análisis y visualización.

El material utiliza datos sintéticos, por lo que no contiene información real de personas o empresas.

## Objetivo

Facilitar el aprendizaje práctico del análisis de datos, mediante explicaciones, ejemplos de código y ejercicios que permitan comprender los procedimientos y sus resultados.

## Contenido del repositorio

### Análisis de datos con R

- Creación de conjuntos de datos.
- Exploración de estructuras y tipos de variables.
- Preparación y transformación de datos.
- Agrupación y cálculo de indicadores.
- Análisis de variaciones porcentuales.
- Visualización de resultados con `ggplot2`.
- Comprobación de resultados.

### Análisis de datos con Python

- Generación de datos con NumPy y pandas.
- Exploración de tablas mediante `info()` y `head()`.
- Conversión y preparación de variables.
- Agrupación de registros con `groupby()`.
- Cálculo de variaciones mensuales.
- Visualización con Matplotlib.
- Verificación de cálculos.

## Herramientas utilizadas

**R:** RStudio, tidyverse, lubridate, janitor y ggplot2.

**Python:** pandas, NumPy y Matplotlib.

**Documentación:** Quarto y Markdown.

## Cómo utilizar los manuales

1. Descargar o clonar el repositorio.
2. Abrir el archivo `.qmd` correspondiente al lenguaje que se desea estudiar.
3. Instalar las bibliotecas utilizadas en los ejercicios.
4. Ejecutar los bloques de código en el orden presentado.
5. Revisar los resultados y desarrollar las actividades de interpretación.

## Estado del proyecto

Material educativo en desarrollo. Se agregarán nuevas secciones y ejercicios a medida que avance la elaboración de los manuales.

## Uso del material

Este repositorio tiene fines educativos y de aprendizaje. Los ejemplos pueden utilizarse como referencia para practicar análisis de datos.
